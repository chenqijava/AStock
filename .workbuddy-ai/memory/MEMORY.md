# AStock 项目长期记忆

## 项目概述
A 股量化交易策略回测与实盘信号系统，包含 11 个策略 + 共享模块 + 实盘部署。
核心策略：恐慌日超跌反弹 (strategy_panic.py)，十年十正，CAGR 8.2%，夏普 1.28。

## 关键技术决策
- 后复权(hfq)数据避免除权缺口制造假暴跌信号
- 成本模型：佣金万2.5/边 + 印花税千0.5(卖出) + 滑点0.1%/边
- 多进程回测：multiprocessing.Pool + imap_unordered
- Wilder ATR 平滑：ewm(alpha=1/period, adjust=False)
- 流通市值估算：成交额/换手率×100

## 策略评级
- 核心：恐慌超跌(默认) CAGR 8.2% / 稳健型 CAGR 5.2% 回撤2.1%
- 幸存者偏差验证通过：全样本(含195只退市股) ΔCAGR=-0.1%，偏差可忽略
- 观点：可转债双低(高弹高回撤) / 高股息宽带(弱于持有) / 网格ETF(低收益低风险)
- 放弃：MA交叉(0/88组盈利) / 低吸(-99.7%) / 四因子默认(-93%)
- 未回测：海龟/克列诺/双均线/双炮

## 实盘部署
- daily_loop.py: 16:00 自动更新数据→生成信号→推送 TG/微信
- signal_panic.py: 维护 panic_positions.json 持仓台账
- 资金建议 100-200万，每笔2万
